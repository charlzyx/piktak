MACHINE

One daemon.
Many services.

piktakd bridges one or more local HTTP, WebSocket, or TCP services. No changes to the application.

RELAY

Run it
your way.

Deploy the Cloudflare Worker for browser access, or host the Go Relay for transparent TCP.

GO RELAY

Self-hosted,
with a real identity.

For transparent TCP, run piktak-relay on your own server. A one-time pairing code gives the Machine a persistent credential; later reconnects use that credential instead of a shared machine code.

Pair once · reconnect automatically · Cloudflare Worker stays separate

Read the Go Relay guide →

PUBLIC ACCESS

Access is not optional.

Every public browser service needs Cloudflare Access. The machine code attaches a Host; it does not authenticate browser users.
