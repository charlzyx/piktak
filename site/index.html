WHY PIK.TAK为什么做 PIK.TAK

One local service should not require a whole VPN.访问一个本地服务，不该占用整个 VPN。

PIK.TAK started as a way to use DSH and PiAgent from a phone. It now connects any selected HTTP, WebSocket, or TCP service through a Relay you control.PIK.TAK 最初用于从手机访问 DSH 和 PiAgent。现在，它可以通过你控制的 Relay 连接指定的 HTTP、WebSocket 或 TCP 服务。

SERVICE, NOT NETWORK连接服务，不是网络

Connect only what you need.只连接需要的服务。

The Machine dials out. Your phone opens a domain. No public IP, port forwarding, or phone app.Machine 主动连出，手机只需打开域名。不需要公网 IP、端口转发或额外 App。

YOUR RELAY你的 RELAY

Cloudflare or Go.Cloudflare 或 Go。

Deploy the Worker in your account, or run the Go Relay yourself. PIK.TAK does not operate a public tunnel cloud.把 Worker 部署在自己的账号中，或者运行 Go Relay。PIK.TAK 不提供公共中继云服务。

BRIDGE TODAY先用 BRIDGE 接入

Native tomorrow.以后再原生集成。

Bridge existing services without code changes. Native applications can later use pairing, discovery, capabilities, and tunnels directly.现有服务无需改代码即可接入。以后应用可以直接使用配对、发现、能力协商和 Tunnel。

TWO RELAY BACKENDS两种 RELAY

Choose the path that fits.选择适合你的连接方式。

01

Cloudflare Worker

No VPS. HTTPS, custom domains, Access, and Durable Object routing. Cloudflare Access is required for every public Service.不需要 VPS，支持 HTTPS、自定义域名、Access 和 Durable Object 路由。每个公开 Service 都必须配置 Cloudflare Access。

02

Go Relay

Self-hosted, transparent TCP, and no Cloudflare dependency. Raw ingress must be restricted by your network.自建、透明 TCP、不依赖 Cloudflare。Raw ingress 必须由网络边界限制访问。

SECURITY FIRST先配置安全入口

Do not expose a real service without Access.没有 Access，不要开放真实服务。

The machine code only protects Host attachment. It does not authenticate browser users. Configure Cloudflare Access before connecting DSH, an Agent, or an admin panel.机器码只保护 Host 接入，不能认证浏览器用户。连接 DSH、Agent 或管理面板前，必须先配置 Cloudflare Access。
