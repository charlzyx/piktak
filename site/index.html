WHY PIK.TAK

One local service should not require a whole VPN.

PIK.TAK started as a way to use DSH and PiAgent from a phone. It now connects any selected HTTP, WebSocket, or TCP service through a Relay you control.

SERVICE, NOT NETWORK

Connect only what you need.

The Machine dials out. Your phone opens a domain. No public IP, port forwarding, or phone app.

YOUR RELAY

Cloudflare or Go.

Deploy the Worker in your own account, or run the Go Relay yourself. PIK.TAK does not operate a public tunnel cloud.

BRIDGE TODAY

Native tomorrow.

Bridge existing services without code changes. Native applications can later use pairing, discovery, capabilities, and tunnels directly.

TWO RELAY BACKENDS

Choose the path that fits.

01

Cloudflare Worker

No VPS. HTTPS, custom domains, Access, and Durable Object routing. Built for phones and browsers.

02

Go Relay

Self-hosted, transparent TCP, and no Cloudflare dependency. The protocol reference implementation.
